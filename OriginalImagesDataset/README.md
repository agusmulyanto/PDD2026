# PDD2026: Road Pavement Deformation Dataset

## Dataset Access

Due to storage limitations, the PDD2026 dataset is distributed through two repositories:

### Original Images

The original pavement images collected during the data acquisition process are provided in their native resolutions and can be accessed through Google Drive:

🔗 **Google Drive Repository**  
https://drive.google.com/drive/folders/1PhjeT0Okik784VXfbqcIUFtHJCpHWk46?usp=sharing

### Resized Images (1024 × 1024)

For training, validation, and benchmarking purposes, all original images were resized to a standardized resolution of **1024 × 1024 pixels**. The resized dataset is available through Mendeley Data:

🔗 **Mendeley Data Repository**  
http://dx.doi.org/10.17632/fgtjn9kjkd.2

## Notes

- The Google Drive repository contains the original images in their native resolutions as collected from multiple acquisition devices.
- The Mendeley Data repository contains the resized images (1024 × 1024 pixels) used for dataset preparation, model training, and benchmarking experiments.
- Both repositories contain the same image content, differing only in image resolution and preprocessing stage.
